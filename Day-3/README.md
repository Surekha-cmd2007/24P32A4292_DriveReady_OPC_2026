

## Overview

This session focuses on building a business-oriented AI assistant using Python, LangChain, and Groq LLM. It explores prompt engineering, conversational memory, response evaluation, and the fundamentals of AI agents using KindCare Companion as a practical example.

## Topics Covered

- Connecting LLMs using LangChain and Groq.
- Creating system prompts and prompt templates.
- Implementing conversational memory.
- Building LangChain chains.
- Testing AI responses using CSV test cases.
- Understanding AI agents and tool-based workflows.

## Business Example: KindCare Companion

A health and wellness assistant designed to provide information about available services, pricing, and appointment policies.





### 1. Plain Code (Python)
Used for fixed operations and calculations.
- Calculating service costs.
- Checking appointment notice requirements.

### 2. One LLM Call
Used for understanding customer queries and generating responses.
- Suggesting wellness services.
- Providing general wellness information.

### 3. AI Agent
Used for tasks requiring multiple tools and decisions.
- Checking appointment availability and booking.
- Retrieving appointment details.

## Testing and Evaluation

- Created customer-question test cases using CSV.
- Evaluated responses using expected keywords.
- Experimented with prompt improvements.
- Compared different temperature settings.
