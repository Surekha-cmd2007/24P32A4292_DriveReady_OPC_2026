# Day 2 – KindCare Companion

## Task Description
Developed an AI-powered healthcare assistance chatbot named KindCare Companion using Python and Groq API.

## Objective
To create a friendly healthcare assistant that provides information about available services and their prices.

## Services
General Wellness Consultation – ₹300
Personalized Diet Plan – ₹500
Basic Health Checkup – ₹800

## Implementation
Python for chatbot development.
Groq API for AI-powered responses.
System prompts to define chatbot behaviour.
JSON for storing service information.
Decorators for logging function calls.
Chat history to maintain conversation context.
Exception handling for API errors.

## Features
Provides healthcare service information.
Answers user queries.
Remembers user details during conversations.
Provides appointment-related information.

## Learning Outcomes
Learned how to configure AI chatbot system messages.
Practiced Python decorators.
Understood API integration.
Learned conversation history management.
Practiced exception handling.
